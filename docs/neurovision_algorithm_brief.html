NeuroVision Face2EEG

Brief algorithm and system explanation
Core idea: the webcam measures facial dynamics. A trained model uses those dynamics to predict EEG-related signals. The system does not measure EEG through the camera.

1. End-to-end pipeline

Camera frame -> MediaPipe face landmarks and blendshapes -> geometric, blink, mouth, pose, motion and action-unit features -> 64-frame temporal window -> Transformer encoder -> predicted EEG waveform, band power, spectrum and uncertainty Feature windows -> subject normalization -> PCA -> Gaussian Mixture Model (GMM) -> descriptive facial-state cluster probabilities

2. Facial feature extraction

Each frame is converted into measurable facial signals:

  • Eye Aspect Ratio (EAR), blink events and rolling blink rate.
  • Mouth Aspect Ratio (MAR) and jaw opening.
  • Head pose: pitch, yaw and roll.
  • Landmark velocity, acceleration and movement energy.
  • MediaPipe blendshapes mapped to approximate action-unit intensities.

These measurements are grouped into a temporal window of 64 frames, preserving short-term facial behavior rather than using only one image.

Implementation: neurovision/preprocessing/facial.py and neurovision/app/live_tab.py.

3. Why Gaussian Mixture Model clustering?

The project does not start with labeled facial-state categories. Instead, it discovers recurring patterns in facial behavior. A GMM is suitable because facial behavior is continuous and a window can partially resemble more than one state.

  • It models each state as a Gaussian distribution in feature space.
  • It produces soft probabilities, not only a hard label.
  • It can represent clusters with different sizes, orientations and variances.
  • It gives a useful uncertainty signal when a window lies between states.

Before GMM, features are normalized per subject and reduced with PCA. PCA preserves 95% of the variance. The system tests component counts from 2 to 8 and diagonal or full covariance models, selecting the best combination using Bayesian Information Criterion (BIC).

How the GMM algorithm works

  1. Initialize: create candidate Gaussian components.
  2. Expectation step: calculate the probability that each window belongs to each component.
  3. Maximization step: update each component mean, covariance and mixture weight.
  4. Repeat: continue until the likelihood converges.
  5. Select: choose the model with the lowest BIC on training data.
Important: names such as "frequent blinking" or "high head motion" are descriptive suggestions generated from cluster averages. They are not emotions, diagnoses or brain states.

4. Classification versus clustering

There is no conventional supervised classifier in the live pipeline. There is no labeled softmax model trained to classify emotions or clinical states.

TermWhat happens here
ClusteringGMM discovers facial behavior groups without class labels.
Cluster assignmentThe live window is assigned to the highest-probability GMM component.
Displayed stateA descriptive name is attached to that component after inspecting its feature averages.
ClassificationOnly used informally to describe the cluster assignment; it is not supervised classification.

K-Means is also evaluated as a comparison method, but GMM is the primary clustering method because it provides probabilities.

5. EEG regression model

The EEG prediction task is supervised regression. Training data contains synchronized facial windows and EEG targets. The default deep architecture is a Transformer encoder:

  • Layer normalization and linear feature projection.
  • Learned temporal representation using positional encoding.
  • Three Transformer encoder layers with four attention heads.
  • Mean pooling across the 64-frame sequence.
  • Multiple regression heads for different EEG outputs.
OutputMeaning
Waveform128 predicted EEG samples.
Band powerFive continuous values: delta, theta, alpha, beta and gamma.
Spectrum64 spectral-bin values.
UncertaintyPredicted variance-related values used to estimate confidence.

6. Training objective

The model uses a multitask loss so it learns both the waveform shape and its frequency characteristics:

  • Smooth L1 loss for waveform accuracy.
  • Fourier-domain loss for spectral similarity.
  • Mean squared error for band power.
  • Pearson correlation loss for matching waveform shape.
  • Heteroscedastic uncertainty loss for confidence estimation.

Training and validation are subject-independent: windows from the same subject are not allowed to appear in both splits. This reduces subject leakage.

7. Additional classical regression experiment

The clustering analysis also compares three multi-output regressors:

  • Ridge regression
  • RBF-kernel Support Vector Regression
  • Gradient Boosting regression

Each is tested with compact facial features alone and with facial features plus GMM cluster probabilities. This checks whether the discovered facial-state information improves EEG prediction.

8. Interpretation and limitations

  • EEG values shown in the live dashboard are model predictions, not camera measurements.
  • GMM states describe facial behavior and should not be interpreted as emotions or neurological diagnoses.
  • Predicted alpha, beta or other band values should be validated against real EEG recordings.
  • Subject-independent evaluation is essential because facial style and EEG patterns vary across people.
